# banco de pautas — ProgramaDora

Lista de ideias de posts para as rotinas automáticas (06h/20h) considerarem.

Como usar (para a rotina):
- Se houver uma **novidade forte e verificável** das últimas 24h, ela tem prioridade (é a alma do blog).
- Se não houver, escolha **uma** ideia deste banco que ainda não virou post e escreva no formato evergreen.
- Toda afirmação factual continua precisando de fonte + dupla verificação. Ideia daqui **não dispensa** checagem.
- Esta lista é um pool de sugestões, não uma fila consumível: não precisa editá-la ao publicar.
